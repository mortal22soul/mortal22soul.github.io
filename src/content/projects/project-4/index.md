- Engineered a real-time safety platform with geofencing and safe routing algorithms using Next.js and FastAPI.
  Built an OpenCV-based person detection model using CCTV data and an audio classification model for detecting distress signals.
  Deployed containerized microservices on AWS EC2 via Docker and Nginx as a reverse proxy.
